# Security

## Supported version

Only `main` is supported. This project is pre-1.0 and not production-ready.

## Reporting a vulnerability

Report privately through [GitHub's private vulnerability reporting](https://github.com/H3atman/open-shope/security/advisories/new).
Never report vulnerabilities in public issues.

Include the affected commit, how and where you run the shop (local or deployed),
steps to reproduce or a minimal proof of concept, and the expected impact.
Redact secrets, credentials, and personal data. Include a suggested fix if you
have one.
